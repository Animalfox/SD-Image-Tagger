# SD Image Tagger

> [!WARNING]  
> This solution isn't complete! It is not recommended to use it now.
> Please wait for a stable version of this package.

This image tagger was created with only one purpose - to help with tag for your SD training image library.

## Setup

Make sure to install the dependencies:

```bash
pnpm i
```

## Development Server

At this moment, you can run an old version of this SD-tagger with the Nuxt UI.

Start the development server on `http://localhost:3000`:

```bash
pnpm run nuxt
```
